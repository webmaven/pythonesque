An offline, seed-deterministic generator of absurdist institutional titles with Monty Python-inspired enhancements.

== Why pythonesque?

Generates deterministic, reproducible absurdist titles in the spirit of Monty Python's bureaucratic humor.
Think *The Ministry of Silly Walks*, *The Spanish Inquisition*, *The Argument Clinic*, *The Cheese Shop*—
but algorithmically composed from modular templates with hundreds of Python-flavored terms.

Useful for:

* Test data generation (predictable but varied)
* Creative writing prompts and world-building
* Naming things (servers, projects, meeting rooms, databases)
* Deterministic chaos for demos and presentations

== One-Liner Demo

[source,console]

$ pythonesque -c 3 -s "demo"

== Quick Start

[source,console]
----
# Generate a single title
pythonesque

# Generate 5 titles with a custom seed
pythonesque -s "my-seed" -c 5

# Generate unique titles as JSON
pythonesque -u -c 3 -f json

# Generate with slugs in CSV format
pythonesque -g -c 2 -f csv
----

== Usage (Python API)

[source,python]
----
from pythonesque import UnifiedFoundationalGenerator

# Basic usage
generator = UnifiedFoundationalGenerator(seed="The Larch")
print(generator.generate())
print(generator.generate(slugify=True))

# Enhanced API features
print("--- Multiple titles ---")
titles = generator.generate_multiple(5)
for i, title in enumerate(titles, 1):
    print(f"{i}. {title}")

print("--- Unique titles ---")
unique_titles = generator.generate_unique(3)
for i, title in enumerate(unique_titles, 1):
    print(f"{i}. {title}")

print("--- Generator info ---")
print(f"Seed: {generator.get_seed()}")
stats = generator.get_template_stats()
print(f"Template categories: {len(stats)}")
print(f"Most options in: {max(stats, key=stats.get)} ({stats[max(stats, key=stats.get)]} options)")

# Template inspection
print("--- Available categories ---")
categories = generator.list_templates()
print(f"First 5 categories: {list(categories.keys())[:5]}")
----

== CLI Usage

[source,console]
----
# Basic generation
pythonesque                          # Generate one title
pythonesque -s "test"                # Custom seed
pythonesque -c 5                     # Five titles
pythonesque -u                       # Unique titles (boolean flag)
pythonesque -g                       # Title and slug pairs
pythonesque -x 3                     # Exactly 3 elements
pythonesque -x 2-4                   # 2-4 elements range
pythonesque -n                       # Strip leading "The"
pythonesque -c 3 -f json             # JSON output
pythonesque -c 2 -f csv              # CSV output
pythonesque -c 2 -f tsv              # TSV output
pythonesque --version                # Show version
pythonesque -h                       # Show help
----

== Features

* Seed-deterministic generation for reproducible results
* Absurdist institutional titles in the spirit of Monty Python
* Modular template system for vast output variety
* Enhanced with hundreds of Python-inspired absurd terms
* URL-safe slug generation option
* Isolated random number generator (doesn't affect global state)

=== Enhanced API
* Batch generation (`generate_multiple`)
* Unique title generation (`generate_unique`)
* Seed retrieval (`get_seed`)
* Template introspection (`get_template_stats`, `list_templates`)
* Complexity control (exact count or min-max range)
* Leading "The" stripping option

=== CLI
* Full-featured command-line interface
* Multiple output formats: plain text, JSON, CSV, TSV
* Deterministic seed-based generation
* Unique title filtering
* Complexity and format controls

== Complexity and Leading "The" Control

The generator supports optional control over title complexity and leading article, plus improved slugification:

[source,python]
----
from pythonesque import UnifiedFoundationalGenerator

gen = UnifiedFoundationalGenerator("demo")

# Exact complexity control
print("Exactly 3 elements:")
for _ in range(3):
    print(f"  {gen.generate(complexity=3)}")

# Range complexity control
print("\nRange 2-4 elements:")
for _ in range(3):
    print(f"  {gen.generate(complexity=(2,4))}")

# No leading "The"
print("\nNo leading 'The':")
for _ in range(3):
    print(f"  {gen.generate(allow_leading_the=False)}")

# Improved slugification
print("\nSlugified output:")
print(f"  {gen.generate(slugify=True)}")

# Combined controls
print("\nComplexity 3-5, no leading 'The', slugified:")
for _ in range(3):
    print(f"  {gen.generate(complexity=(3,5), allow_leading_the=False, slugify=True)}")
----
