= pythonesque
:toc:

An offline, seed-deterministic generator of absurdist institutional titles with Monty Python-inspired enhancements.

== Installation

[source,console]
----
pip install pythonesque
----

== Usage

[source,python]
----
from pythonesque import UnifiedFoundationalGenerator

# Basic usage (unchanged)
generator = UnifiedFoundationalGenerator(seed="The Larch")
print(generator.generate())
print(generator.generate(slugify=True))

# Enhanced API features
print("--- Multiple titles ---")
titles = generator.generate_multiple(5)
for i, title in enumerate(titles, 1):
    print(f"{i}. {title}")

print("--- Unique titles ---")
unique_titles = generator.generate_unique(3)
for i, title in enumerate(unique_titles, 1):
    print(f"{i}. {title}")

print("--- Generator info ---")
print(f"Seed: {generator.get_seed()}")
stats = generator.get_template_stats()
print(f"Template categories: {len(stats)}")
print(f"Most options in: {max(stats, key=stats.get)} ({stats[max(stats, key=stats.get)]} options)")

# Template inspection
print("--- Available categories ---")
categories = generator.list_templates()
print(f"First 5 categories: {list(categories.keys())[:5]}")
----

== Features

* Seed-deterministic generation for reproducible results
* Absurdist institutional titles in the spirit of Monty Python
* Modular template system for vast output variety
* Enhanced with hundreds of Python-inspired absurd terms
* URL-safe slug generation option
* Isolated random number generator (doesn't affect global state)
* **Enhanced API:**
  * Batch generation (`generate_multiple`)
  * Unique title generation (`generate_unique`)
  * Seed retrieval (`get_seed`)
  - Template introspection (`get_template_stats`, `list_templates`)

== Complexity and Leading "The" Control

The generator now supports optional control over title complexity and leading article:

[source,python]
----
from pythonesque import UnifiedFoundationalGenerator

gen = UnifiedFoundationalGenerator("demo")

# Exact complexity control
print("Exactly 3 elements:")
for _ in range(3):
    print(f"  {gen.generate(complexity=3)}")

# Range complexity control
print("\\nRange 2-4 elements:")
for _ in range(3):
    print(f"  {gen.generate(complexity=(2,4))}")

# No leading "The"
print("\\nNo leading 'The':")
for _ in range(3):
    print(f"  {gen.generate(allow_leading_the=False)}")

# Combined controls
print("\\nComplexity 3-5, no leading 'The':")
for _ in range(3):
    print(f"  {gen.generate(complexity=(3,5), allow_leading_the=False)}")
----
