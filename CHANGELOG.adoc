= Changelog

All notable changes to this project are documented here.

== Unreleased

=== Added
* Enhanced generator with Monty Python-inspired absurdist patterns
* Added 35 new grammar categories with hundreds of silly terms (occupations, pursuits, products, etc.)
* Integrated absurd categories into existing templates for expanded variety without length increase
* Deconstructed long templates into modular components for better variability
* **Added API enhancements:**
  * generate_multiple() for batch title generation
  * generate_unique() for guaranteed unique titles
  * get_seed() to retrieve the generator's seed
  * get_template_stats() for template category statistics
  * list_templates() for inspecting available templates and categories
  * **Complexity control:** complexity parameter for exact or range of title lengths
  * **Leading "The" control:** allow_leading_the parameter to strip leading article
  * **Improved slugification:** Enhanced _slugify method with better symbol handling, Unicode transliteration, and hyphen normalization
* Updated documentation to reflect new features
